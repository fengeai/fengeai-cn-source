# fenge_video_creator

`fenge_video_creator` is the video creation service for `fengeai.cn`.

The product goal is not a generic video toolbox. It is a "short-video creation employee" for the Fenge AI Evolution Club content workflow:

1. Turn a topic, article, or pasted text into a video plan.
2. Let the user review the title, voiceover script, and storyboard.
3. Create an async video job.
4. Poll job status until the final video is ready.

## First provider choice

The first real provider should be a China-accessible video API, preferably Volcengine Jimeng / Seedance or Alibaba Cloud Bailian Kling-style video generation, depending on account availability and price.

The code starts with a `mock` provider so the workflow can be built and tested without burning model credits or committing secrets.

## Quality controls

The UI supports three render modes:

- Draft: low-cost default model from `VIDEO_MODEL`.
- Better: optional model from `VIDEO_QUALITY_MODEL`.
- Final: optional model from `VIDEO_FINAL_MODEL`.

Custom character consistency is supported through either:

- a public reference image URL
- a local image upload that the service exposes under `/video/uploads/...`

For production, set `VIDEO_PUBLIC_BASE_URL=https://fengeai.cn` so provider requests receive a fetchable public URL instead of `127.0.0.1`.

When a reference image is provided, the provider can use `VIDEO_REFERENCE_MODEL` so image/reference-to-video jobs are not sent to a text-only or incompatible model.

```powershell
npm run dev
```

Open:

```text
http://127.0.0.1:3030/video/
```

## API shape

- `GET /video/api/health`
- `GET /video/api/provider/health`
- `POST /video/api/projects`
- `POST /video/api/projects/:id/plan`
- `PUT /video/api/projects/:id/plan`
- `POST /video/api/projects/:id/jobs`
- `GET /video/api/jobs/:id`

Video plans are generated by `VIDEO_LLM_*` when configured. If those variables are empty, the service reuses `ASSISTANT_*`. If neither is present, it uses a local fallback plan for development only.

## Deployment note

This service is designed to run as a standalone module next to:

- `content_factory`
- `fenge_assistant`
- `fenge_upload_service`
- `fenge_wechat_format`

Production routing can later expose it as `https://fengeai.cn/video/`.
